# QUINTET real-environment SQA campaign (E12): results

**Plan.** `TEST_PLAN.md` holds the pass criteria, fixed before execution, plus dated clarifications.

**Environment.**
- One 4-core cloud VM running Docker 29 with private bridge networking.
- Toxiproxy 2.x for network faults.
- 5 coordinator containers and 6 worker containers. The workers are the simulated executor devices, each limited to 0.5 CPU and 192 MB.
- The workers sign their evidence (Ed25519) and the coordinators repair with **TWGR-S**.

**Data.**
- Final run: `results/raw/e12_sqa.jsonl`.
- Every earlier run, kept as evidence: `results/raw/e12_sqa_run*.jsonl`.
- Tables are regenerated by `python3 -I analysis/stage7_figures.py`.

## The majority-adversary loophole (reported after run 8) and its fix
In runs 1–8 the coordinators repaired with plain TWGR. Plain TWGR is safe only while the honest anchor domains of a record outnumber the compromised ones; Theorem 1 says this bound is tight. Beyond it, repair could accept forged records and **add false confirmations**: in E11, 324 of 324 majority attacks on Confirmations succeeded. TWGR-S takes votes off the evidence path:
- **Origin signatures:** devices sign requests and outcomes, with keys listed in a manifest published before the run.
- **Derivation dominance:** budgets, weights, keys and confirmations are always recomputed.
- **Unsigned means unknown:** only crash results may be unsigned, and a confirmation must hold for every possible value of them.

The proof is Theorem 3 in `docs/stage7_quintet_hkg_twgr.md` §4b. Run 9 was the first signed run.

## Defects found by the campaign
Every defect has a regression test, in `tests/test_quintet_service.py` or `tests/test_hkg_quintet.py`.

| ID | Found in | Defect | Severity | Fix |
|---|---|---|---|---|
| D1 | run 1 | A bit flip inside a stored id crashed a coordinator's restart | availability | Defensive id parsing |
| D2 | run 2 | A Recorder that had lost a Result locally expired that slot after restart and **anchored a fabricated crash result** | **integrity** | Check the Archivist's anchors and the witnesses first; postpone if unknown |
| D3 | run 2 | Restart resync re-offered damaged copies *with receipts*, giving them votes | **integrity (latent)** | Re-offer only anchor-verified copies, without receipts |
| D4 | run 3 | A coordinator restarted on a damaged store acted on unverified local data | **integrity** | *Repair before serve* |
| D5 | run 4 | Id counters ignored surviving neighbouring records, so an id was reused | integrity (write-once) | Counters cover every record type keyed by the id |
| D6 | run 5 | A quarantined, corrupted Result was served to the Arbiter; the resulting failing control message blocked replication | **integrity + liveness** | *Anchor-verified reads*; separate data and control queues |
| D7 | run 6 | A restart crashed while rebuilding state from a bit-flipped record | availability | Rebuild from verified records only; restart fuzz test |
| L1 | after run 8 (user report) | **Majority adversary:** repair could accept forged records and add confirmations | **integrity (design)** | TWGR-S (above) |
| L2 | while building TWGR-S | Signed records whose *unsigned parts* had been altered were admissible: edges, an extra field, an upper-case hex signature | integrity of stored bytes; statistical content unaffected | Strict payload and encoding; edges rebuilt from the schema, from accepted or derivable neighbours, and from anchor-backed digests |
| L3 | run 9/10 | A link to a destroyed record copied a corrupted digest when copies tied | link bytes only | Tie-break by well-formedness and anchor support; derivable targets recomputed |

Harness issues (not product defects):
- a race in TC7, where a worker finished before it could be killed;
- container-name reuse in TC12;
- criterion clarifications, all dated in `TEST_PLAN.md`:
  - TC10's "minority" is evaluated per target;
  - TC12 is scoped to records written after the repair;
  - for signed evidence, "wrong" means wrong *content*, while link-only byte differences are reported separately;
  - TC10 was extended to k = 1…5 after the loophole fix.

**Lessons.**
1. The algorithm can be proven correct while the service around it is not. Every integrity defect D2–D6 came from a coordinator trusting its own storage after a fault. They were fixed by *repair before serve* and *anchor-verified reads*.
2. A quorum bound that is tight is still a loophole. The fix is to make authenticity independent of votes: origin signatures plus derivation, so that an adversary holding every coordinator can only destroy evidence, never create it.
